# Generic Resume Tailor Script — Usage Guide

## Overview
`tailor_resume_generic.sh` is a production-ready, shareable resume tailoring tool that works for **any candidate** with **any resume file**. It removes all hardcoded personal information and paths from the original non-generic version.

## Features Completed ✅

### Argument Parsing & Path Management
- ✅ `--base-resume <path>` (required): Path to comprehensive resume markdown
- ✅ `--candidate-name <name>` (optional): Auto-extracted from resume H1 if omitted
- ✅ `--output-dir <path>` (optional): Defaults to `./companies/`
- ✅ `--force`: Skip score gate and generate anyway
- ✅ `job-url` (required, positional): LinkedIn, Lever, or Greenhouse URL
- ✅ Built-in validator: Included in repo, always runs (no need to provide path)

### Job Description Handling
- ✅ Fetches JD from multiple platforms (LinkedIn with session cookie, Lever, Greenhouse)
- ✅ Saves JD to `companies/<company>/<company>_jd.md`
- ✅ Auto-detects company name from JD content or URL
- ✅ Prompts user to confirm/override company name

### Resume Scoring & Decision Gates
- ✅ Analyzes JD against resume using wibey agent
- ✅ Scores match 0-100 with detailed requirement-by-requirement table
- ✅ Verdict system:
  - `AUTO_PROCEED` (score ≥80): Generate without confirmation
  - `CONFIRM` (60-79): Ask user for confirmation
  - `SKIP` (<60): Skip unless `--force` provided

### Resume Generation (Two-Phase Architecture)
- ✅ **Phase 1**: wibey agent generates Python resume script
  - Selects relevant bullets from comprehensive resume
  - Reorders by JD relevance
  - Targets 2-page format (18-22 bullets)
  - Script saved to `companies/<company>/generate_resume_<company>.py`

- ✅ **Phase 2 (if validator provided)**: Validation + Auto-Fix Loop
  - Runs validator on generated script
  - Auto-fixes violations (up to 2 attempts)
  - Falls back to manual intervention if all attempts fail

- ✅ **Phase 3**: Generates output
  - Executes script to create PDF and DOCX resumes
  - Outputs to same directory as script

### Interview Prep (Bonus)
- ✅ Generates interview prep research document
- ✅ Outputs company overview, tech stack, culture, prep focus areas
- ✅ Renders as formatted PDF with score annotation

## Installation & Setup

### 1. Install Dependencies
```bash
# Python packages
pip install python-docx reportlab fpdf2 anthropic openai requests

# For LinkedIn JD fetching, save LinkedIn session cookie
echo "your_li_at_token_here" > ~/.wibey/linkedin_cookies.txt
chmod 600 ~/.wibey/linkedin_cookies.txt
```

### 2. Set Up Wibey
The script uses `wibey agent` under the hood. Ensure your wibey installation is working:
```bash
wibey --version
```

### 3. Prepare Comprehensive Resume
Create a markdown resume file with:
- H1 title line: `# CandidateName — JobTitle`
- All job experiences with bullet points
- Skills section
- Education section

Example:
```markdown
# Jane Doe — Senior Software Engineer

**Email: jane@example.com | LinkedIn: linkedin.com/in/janedoe**

## Experience

### Company A | Senior Engineer | 2020–Present
- Built distributed system handling 1M QPS
- Led migration of 50+ services to Kubernetes

### Company B | Software Engineer | 2018–2020
- Implemented payment processing pipeline
- Mentored 3 junior engineers

## Skills
- Languages: Python, Go, Java, Typescript
- Cloud: AWS, GCP, Kubernetes
- Databases: PostgreSQL, Elasticsearch

## Education
- BS Computer Science, University of California
```

## Usage

### Important: Run from Repository Root

Always run the script from the repository directory, NOT from within the `companies/` folder:

```bash
cd /path/to/resumeTailor
./bin/tailor_resume_generic.sh --base-resume ~/my-resume.md <job-url>

# ❌ WRONG:
cd /path/to/resumeTailor/companies
./tailor_resume_generic.sh ...  # Creates nested companies/companies/
```

### Basic Usage
```bash
./bin/tailor_resume_generic.sh \
  --base-resume ~/my-resume.md \
  https://www.linkedin.com/jobs/view/ABC123/
```

### With Candidate Name Override
```bash
./tailor_resume_generic.sh \
  --base-resume ~/my-resume.md \
  --candidate-name "Jane Doe" \
  https://jobs.lever.co/acme/abc123
```

### With Custom Output Directory
```bash
./tailor_resume_generic.sh \
  --base-resume ~/my-resume.md \
  --output-dir ~/my-company-applications \
  https://greenhouse.io/jobs/123456
```

### Force Generation (Skip Score Gate)
```bash
./tailor_resume_generic.sh \
  --base-resume ~/my-resume.md \
  --force \
  https://www.linkedin.com/jobs/view/ABC123/
```

**Note**: Validation runs automatically — the script includes a built-in validator, no additional setup required.

## Troubleshooting

### LinkedIn JD Fetching Fails
**Issue**: "Please add your LinkedIn session token to ~/.wibey/linkedin_cookies.txt"

**Solution**:
1. Open LinkedIn in your browser
2. Open DevTools → Application → Cookies
3. Find `li_at` cookie, copy its value
4. Save to `~/.wibey/linkedin_cookies.txt`

### Validation Phase Fails
**Issue**: "Validation still failing after 2 fix attempts"

**Solution**:
1. Check generated script: `companies/<company>/generate_resume_<company>.py`
2. Review validator error output for specific rule violations
3. Manually fix script following rules (no metrics, verified bullets, 2 pages max)
4. Re-run Phase 3: `cd companies/<company> && python3 generate_resume_<company>.py`

### Score Gate Blocks Generation
**Issue**: Score <60 (SKIP verdict)

**Solution**:
1. Review the matching table to see which requirements are gaps
2. Either: adjust resume to better match JD, or
3. Use `--force` to override: `./script --force <url>`

### Generated PDF Is Too Long
**Issue**: "Page count exceeded" or PDF is 3+ pages

**Solution**:
1. Check `generate_resume_<company>.py` script
2. Reduce bullet count (target 18-22 total across all jobs)
3. Re-run: `cd companies/<company> && python3 generate_resume_<company>.py`

## Advanced: Validation Script Integration

If you have a validation script (enforces rules like no metrics, verified bullets, 2-page limit):

```bash
./tailor_resume_generic.sh \
  --base-resume ~/comprehensive.md \
  --validator ~/validators/resume_validator.py \
  --output-dir ~/tailored \
  https://www.linkedin.com/jobs/view/ABC123/
```

The script will:
1. Generate resume script (Phase 1)
2. **Validate** generated script against rules (Phase 2a)
3. **Auto-fix** any violations (Phase 2b, up to 2 attempts)
4. **Generate** PDF/DOCX only after clean validation (Phase 3)

## For Tool Authors / CLI Wrappers

To use this script in an automated tool, pipe input for prompts:

```bash
# company-name + confirm generation
echo -e "My Company\ny" | ./tailor_resume_generic.sh \
  --base-resume ~/resume.md \
  https://jobs.example.com/123
```

To extract candidate name from resume programmatically:

```bash
CANDIDATE=$(grep "^#" resume.md | sed 's/^#[[:space:]]*//; s/[[:space:]]*—.*//')
echo "Extracted candidate: $CANDIDATE"
```

## Data Privacy & Security

✅ **This script is completely generic and shareable**:
- No hardcoded personal information
- No hardcoded paths (all configurable)
- No hardcoded company references
- Candidate name extracted from resume, not hardcoded
- All output goes to user-specified directories
- Safe to commit to public repositories

To verify no personal info leaked:
```bash
grep -r "shawn\|s0h0607\|TailoredResumes" resumeTailor/bin/
```
